# Mad-Avionics Spriting Kit
1.1 Diable Avionics addon mod's spriting kit. 

Krita files for the various sprites of Mad Avionics

## Dev directory
Contains references, misc files, and were the original project files used to develop the sprites. Lots of untrimmed excess material, canvas size might not match content inside.

## Export Trims directory
"Final" versions of each sprite. Generally trimmed to be iterated for export of sprites.
